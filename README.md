## Опис проекту

Виконання тестового завдання api сервісу бронювання житла з можливістю безпечного імпорту позицій. Умови авторизації не були прописані в завданні, тому api публічне.

Проект використовує: php, mysql, laravel, docker.

## Інструкція встановлення та запуску

- Зклонувати репозиторій в папку проекту.
- Запустити контейнери
```bash
docker compose up -d
```
- Виконати встановлення пакетів laravel
```bash
docker compose exec php composer install
```
- Створити та налаштувати файл src/.env
- Виконати міграції БД
```bash
docker compose exec php php artisan migrate
```
- Виконати тестове наповнення БД
```bash
docker compose exec php php artisan db:seed
```

## Як користуватись

- api http://localhost:8080/api
- Swagger http://localhost:8080/api/documentation/
- PHPmyadmin http://localhost:8081/
- Параметр кількості об'єктів на сторінку при пошуку в .env PROPERTY_SEARCH_PER_PAGE=10
- Тести
```bash
docker compose exec php php artisan test
docker compose exec php ./vendor/bin/phpunit
```
- Запуск воркеру для обробки черги імпорту
```bash
docker compose exec php php artisan queue:work --queue=default --tries=3 --timeout=120
```
- Одноразовий запуск воркеру
```bash
docker compose exec php php artisan queue:work --queue=default --tries=3 --timeout=120 --stop-when-empty
```
- Приклади пакетів для імпорту в папці import_json

## Пояснення ідемпотентності імпорту

Табличка в бд містить композитний ключ UNIQUE для supplier_id + external_import_id, це обмежує можливість дублювання імпортів в бд. Провалідовані дані імпорту опрацьовуються через createOrFirst() - якщо імпорт новий він додається в бд, якщо спроба дублювання - повертається респонс по існуючому імпорту і новий не створюється. Також за допомогою $import->wasRecentlyCreated створюються джоби лише для нових імпортів, а не для існуючих.

## Пояснення механізму захисту від двох одночасних бронювань останньої одиниці

Для цього використовується механізм транзакцій бд та блокування запису таблички offers. Під час блокування перевіряється доступність одиниць для бронювання та додаткові умови. Якщо можливість бронювання підтверджено -  створюється reservation та зменшується к-сть доступних одиниць на 1. Після завершення транзакції та зняття блокування доступ до цього запису може отримати інший конкурентний запит, який вже буде працювати з актуальними даними.
